## ۱. هدف و دامنه

### ۱٫۱ هدف (Why)
موتور i18n ترجمه، pluralization، format اعداد/تاریخ فارسی و بارگذاری lang files را فراهم می‌کند و پشتیبانی کامل RTL و فارسی‌سازی پیام‌ها را تضمین می‌کند.

### ۱٫۲ دامنه (What)
- ✅ شامل: Translator، PluralRules، PersianFormatter، NumberFormatter، Jalali date integration، helpers
- ❌ خارج از دامنه: تقویم جلالی پایه (در jalali)، Validation messages (در validation)

## ۲. مفاهیم و واژگان
| واژه | تعریف |
|---|---|
| Engine | بستهٔ نرم‌افزاری مستقل در `engines/<name>/` با Service Provider و autoload |
| Service Provider | کلاس ثبت سرویس‌ها در Container و publish config/lang |
| Facade | accessor استاتیک برای دسترسی به سرویس موتور از Container |
| Namespace | پیشوند PSR-4 مخصوص موتور (مثلاً `Tavaan\Engine\I18n\`) |
| ZeroDependency | بدون نیاز به ext-* خارجی یا composer package سنگین |

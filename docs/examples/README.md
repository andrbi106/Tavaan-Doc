## دربارهٔ این بخش 📚

این پوشه (`docs/examples/`) شامل آموزش‌های **گام‌به‌گام و عملی** تَوان است. هر آموزش، یک پروژهٔ کوچک را از صفر تا اجرا می‌سازد. برخلاف مستندات فنی، اینجا تمرکز روی **«چطور»** است، نه «چرا».

اگر [`../00-learn/for-beginners.md`](../00-learn/for-beginners.md) را خواندید و آمادهٔ کدنویسی‌اید، اینجا شروع کنید.

## چطور از آموزش‌ها استفاده کنیم؟ 📖

هر آموزش به این ساختار است:

1. **هدف** — چه می‌سازیم؟
2. **پیش‌نیازها** — چه چیز لازم داریم؟
3. **مراحل** — قدم‌به‌قدم، با کد و توضیح.
4. **تست** — چطور بدانیم کار کرد؟
5. **پاکسازی** — (در صورت نیاز) چطور پاک کنیم.
6. **گام بعدی** — کجا برویم بعد؟

**قاعدهٔ طلایی:** هر بلوک کد را کپی کنید، اجرا کنید، نتیجه را ببینید، بعد سراغ بلوک بعد بروید. **نه همه را یک‌جا کپی.**

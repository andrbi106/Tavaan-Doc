## پیش‌نیازها ✅

| چی | چطور بفهمم؟ |
|---|---|

## مرحله ۱ — نصب PHP (در صورت نیاز) 🔧

اگر PHP ندارید:

### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install php8.3-cli php8.3-mbstring php8.3-xml
```

### macOS (با Homebrew)
```bash
brew install php
```

### Windows
از [php.net](https://www.php.net/downloads) دانلود کنید و به PATH اضافه کنید.

### تست نصب
```bash
php -v
```

خروجی باید چیزی شبیه این باشد:
```
PHP 8.3.32 (cli) (built: ...)
```

---

## مرحله ۲ — دریافت تَوان 📦

تَوان را از مخزن رسمی دریافت کنید. اگر قبلاً دانلود کرده‌اید، این مرحله را رد کنید.

```bash
# در پوشهٔ دلخواهتان
cd ~/projects

# کلون یا دانلود تَوان
# (دستور دقیق بسته به روش انتشار)
# فرض: در پوشهٔ tavaan-project قرار دارد
cd tavaan-project
```

ساختار پوشه پس از ورود:

```
tavaan-project/
├── bin/tvn              ← ابزار CLI
├── public/index.php     ← نقطهٔ ورود HTTP
├── bootstrap.php
├── core/                ← هسته
├── engines/             ← موتورها
├── config/
├── routes/
└── ...
```

## مرحله ۳ — ساخت فایل محیطی 🌱

یک فایل به‌نام `.env` می‌سازیم که تنظیمات محلی شما در آن است.

```bash
# از قالب نمونه کپی کنید
cp .env.example .env
```

اگر `.env.example` وجود نداشت، خودتان بسازید:

```bash
cat > .env << 'EOF'
TVN_ENV=development
TVN_DEBUG=true
TVN_BASE_PATH=.
EOF
```

> **تمثیل:** فایل `.env` مثل «تنظیمات کاربری» در گوشی‌تان است — مخصوص همین دستگاه، نه قابل اشتراک.

---

## مرحله ۴ — اجرای سرور توسعه 🚀

حالا تَوان را اجرا می‌کنیم:

```bash
php bin/tvn serve
```

خروجی:
```
Tavaan development server started on http://127.0.0.1:8000
Press Ctrl+C to stop
```

سرور در حال اجراست. این پنجرهٔ ترمینال را **باز نگه دارید** — اگر ببندید، سرور متوقف می‌شود.

> **تمثیل:** مثل روشن کردن چراغ خانه — تا زمانی که کلید را نزده‌اید، خانه تاریک است.

---

## مرحله ۵ — اولین صفحه در مرورگر 🌐

مرورگرتان را باز کنید و به این آدرس بروید:

```
http://127.0.0.1:8000
```

شما باید صفحهٔ خوش‌آمدگویی تَوان را ببینید — چیزی شبیه:

```
به تَوان خوش آمدید! 🎉

نسخه: 0.4.0
تعداد موتورها: 52
PHP: 8.3.32
```

**تبریک!** اولین صفحهٔ تَوان را دیدید.

---

## مرحله ۶ — آشنایی با دستورات CLI ⌨️

یک ترمینال **جدید** باز کنید (ترمینال قبلی که سرور در آن اجراست را نبندید). این دستورات را امتحان کنید:

```bash
php bin/tvn version
# خروجی: Tavaan 0.4.0

php bin/tvn info
# خروجی: اطلاعات سیستم

php bin/tvn engines
# خروجی: لیست ۵۲ موتور نصب‌شده
```

> **تمثیل:** `bin/tvn` مثل یک «سوییچ چندکاره» است — با آن می‌توانید همه‌چیز را در تَوان کنترل کنید.

---

## مرحله ۷ — ساخت اولین مسیر (Route) 🛤️

حالا یک مسیر سفارشی می‌سازیم. در ویرایشگرتان، فایل زیر را باز کنید:

```
routes/web.php
```

اگر فایل وجود نداشت، آن را بسازید. محتوای فعلی را ببینید و این مسیر را به آن **اضافه** کنید:

```php
<?php
declare(strict_types=1);

use Tavaan\Engine\Router\Route;

// مسیرهای پیش‌فرض تَوان (اگر هست)
Route::get('/', function () {
    return 'به تَوان خوش آمدید!';
});

// ⬇️ مسیر جدید شما ⬇️
Route::get('/hello', function () {
    return 'سلام، دنیا! 🌍';
});
```

فایل را ذخیره کنید.

## مرحله ۸ — تست مسیر جدید ✅

در مرورگر، به آدرس زیر بروید:

```
http://127.0.0.1:8000/hello
```

شما باید ببینید:

```
سلام، دنیا! 🌍
```

**تبریک!** شما اولین مسیر تَوان را ساختید.

---

## مرحله ۹ — مسیر با پارامتر 🎯

حالا یک مسیر هوشمندتر می‌سازیم که نام کاربر را بگیرد. در همان فایل `routes/web.php`:

```php
Route::get('/greet/{name}', function (string $name) {
    return "سلام، {$name}! 👋";
});
```

ذخیره کنید. در مرورگر:

```
http://127.0.0.1:8000/greet/Ali
```

خروجی:
```
سلام، Ali! 👋
```

امتحان کنید:
```
http://127.0.0.1:8000/greet/Maryam
http://127.0.0.1:8000/greet/تَوان
```

> **تمثیل:** پارامتر `{name}` مثل یک جای خالی در فرم است — تَوان آن را با چیزی که کاربر در URL می‌زند، پر می‌کند.

---

## مرحله ۱۰ — آشنایی با JSON API 📦

حالا یک مسیر می‌سازیم که به‌جای متن، JSON برمی‌گرداند (مفید برای API):

```php
Route::get('/api/hello', function () {
    return [
        'message' => 'سلام، دنیا!',
        'framework' => 'Tavaan',
        'version' => '0.4.0',
    ];
});
```

در مرورگر:
```
http://127.0.0.1:8000/api/hello
```

خروجی:
```json
{
    "message": "سلام، دنیا!",
    "framework": "Tavaan",
    "version": "0.4.0"
}
```

> **نکته:** تَوان به‌طور خودکار آرایه را به JSON تبدیل می‌کند. مثل یک مترجم که می‌داند چه زمانی فارسی صحبت کند و چه زمانی انگلیسی.

## عیب‌یابی ⚠️

| مشکل | راه‌حل |
|---|---|
| «command not found: php» | PHP در PATH نیست — نصب را دوباره چک کنید |
| «سرور اجرا نشد» | پورت ۸۰۰۰ ممکن است اشغال باشد — `php bin/tvn serve --port=8001` |
| «۴۰۴ در /hello» | فایل `routes/web.php` را ذخیره کرده‌اید؟ |
| «خطای نحوی (syntax error)» | ویرایشگرتان encoding UTF-8 است؟ |
| «صفحه سفید» | لاگ را در `storage/logs/` ببینید |

## پاکسازی 🧹

وقتی کارتان تمام شد، در ترمینالی که سرور در حال اجراست، `Ctrl+C` بزنید تا متوقف شود.

```bash
# (در ترمینال سرور)
^C
# خروجی: Server stopped.
```

فایل‌های ساخته‌شده (`.env`، تغییرات `routes/web.php`) را می‌توانید نگه دارید یا برگردانید.

## اگر تازه شروع کرده‌اید 👋

سلام! اگر این فایل را می‌خوانید، احتمالاً یکی از این حالت‌ها در شما هست:

- تازه برنامه‌نویسی را شروع کرده‌اید و کلمهٔ «فریمورک» برایتان ناآشناست.
- کمی PHP بلدید اما نمی‌دانید «تَوان» چیست.
- کنجکاو هستید بدانید یک فریمورک از درون چطور کار می‌کند.

هر کدام از این‌ها باشید، در جای درستی هستید. این فایل را در ۱۵ دقیقه می‌خوانید و در پایان، می‌فهمید تَوان چیست، چرا وجود دارد، و چطور می‌توانید وارد دنیای آن شوید.

هیچ پیش‌فرضی نداریم. هیچ واژهٔ ناآشنا بدون توضیح نمی‌گذاریم. با هم قدم‌به‌قدم جلو می‌رویم. 🚶

## فریمورک چیست؟ 📖

تصور کنید می‌خواهید کیک شوکولاتی درست کنید. دو راه دارید:

**راه اول:** بروید به فروشگاه و یک کیک آماده بخرید. سریع، اما دست‌پخت خودتان در کار نیست.

**راه دوم:** از یک **کتاب دستور پخت** (recipe book) استفاده کنید. کتاب به شما می‌گوید: «۲ پیمانه آرد، ۳ تخم‌مرغ، ۵۰ گرم کاکائو». شما خودتان مواد را ترکیب می‌کنید، در فر می‌گذارید، و کیک شما می‌شود.

**فریمورک (Framework)** همان کتاب دستور پخت است.

وقتی می‌خواهید یک وب‌سایت بسازید، کارهای تکراری زیادی هست: گرفتن ورودی از کاربر، مسیریابی درخواست، اتصال به پایگاه‌داده، نمایش HTML. اگر هر بار از صفر بنویسید، خسته می‌شوید. فریمورک این کارهای تکراری را برایتان آماده می‌کند؛ مثل کتاب دستور پخت که می‌گوید «برای ساخت وب‌سایت: اول این، بعد این».

تَوان یک فریمورک است — کتاب دستور پخت ساخت وب‌سایت با PHP.

---

## PHP چیست؟ 🐘

PHP یک **زبان برنامه‌نویسی** است که روی سرور اجرا می‌شود. یعنی چی؟

وقتی شما در مرورگرتان آدرس `example.com` را می‌زنید، کامپیوتر شما (مرورگر) از سرور درخواست می‌کند: «صفحهٔ اصلی را بده». سرور، که PHP روی آن نصب است، کد PHP را اجرا می‌کند، خروجی (معمولاً HTML) را می‌سازد، و به مرورگر شما می‌فرستد. شما HTML را می‌بینید.

چرا PHP؟ چون:
- **ساده است:** یادگیری‌اش نسبتاً سریع است.
- **هر جا هست:** بیش از ۷۰٪ وب‌سایت‌های دنیا از PHP استفاده می‌کنند.
- **قدرتمند است:** سایت‌هایی مثل Facebook، Wikipedia، WordPress با PHP ساخته شده‌اند.

PHP مثل یک قاشق غذاخوری است — ساده، اما می‌توان با آن غذاهای خیلی پیچیده بخورید. 🥄

---

## تَوان چیست؟ 🌟

تَوان (به‌معنای «توانایی، قدرت») یک فریمورک PHP است که سه ویژگی خاص دارد:

1. **صفر‌وابستگی (ZeroDependency):** تَوان هیچ پکیج بیرونی ندارد. همه‌چیز — از مسیریاب تا پایگاه‌داده — خودنوشته است. مثل کسی که خانه‌اش را آجر به آجر خودش می‌سازد.
2. **فارسی‌اول:** تَوان از روز اول برای فارسی‌زبانان طراحی شده: تاریخ جلالی، پشتیبانی RTL، نیم‌فاصله.
3. **خودکفایی:** می‌توانید تَوان را بدون اینترنت اجرا کنید.

به زبان ساده: **تَوان یک فریمورک PHP است که با آن می‌توانید وب‌سایت بسازید، بدون آنکه به ابزارهای بیرونی وابسته باشید.**

## قبل از شروع تَوان، چه باید بدانید؟ ✅

تَوان ساده است، اما PHP را تا حدی باید بلد باشید. حداقل‌ها:

| مفهوم | باید بدانید… |
|---|---|
| **متغیر (Variable)** | چطور یک مقدار را در `$name = 'ali'` ذخیره کنید. |
| **تابع (Function)** | چورت یک تابع ساده بنویسید: `function add($a, $b) { return $a + $b; }`. |
| **کلاس (Class)** | یک کلاس ساده با یک ویژگی و یک متد. |
| **آرایه (Array)** | چطور یک لیست بسازید و روی آن حلقه بزنید. |
| **if/else** | شرط ساده. |

اگر این‌ها را بلدید، آماده‌اید. اگر نه، یک هفته با آموزش‌های رایگان PHP در YouTube تمرین کنید و برگردید. ما اینجا منتظر شما هستیم. 😊

## واژه‌نامهٔ مینی 📖

برای شروع، این چند واژه را بدانید. (واژه‌نامهٔ کامل در [`glossary-simple.md`](./glossary-simple.md).)

### متغیر (Variable) 📦
یک جعبه برای نگه‌داشتن یک مقدار.

```php
$name = 'Ali';
$age = 16;
```

> **تمثیل:** مثل یک لیبل روی یک جعبه. روی جعبه نوشته «name» و داخلش «Ali» است.

### تابع (Function) 🔧
یک دستورالعمل که کاری انجام می‌دهد و می‌تواند خروجی بدهد.

```php
function greet($name) {
    return "سلام، $name!";
}

echo greet('Ali');  // خروجی: سلام، Ali!
```

> **تمثیل:** مثل یک دستگاه اسپرسوساز. دانهٔ قهوه می‌گیرد، اسپرسو می‌دهد.

### کلاس (Class) 🏛️
یک «طرح» برای ساخت اشیاء. مثل نقشهٔ یک خانه — می‌توانید چند خانه با همان نقشه بسازید.

```php
class Person {
    public string $name;

    public function __construct(string $name) {
        $this->name = $name;
    }

    public function sayHello(): string {
        return "سلام، من {$this->name} هستم.";
    }
}

$ali = new Person('Ali');
echo $ali->sayHello();  // خروجی: سلام، من Ali هستم.
```

> **تمثیل:** نقشهٔ خانه — طبقهٔ همکف، اتاق خواب، آشپزخانه. حالا می‌توانید چند خانه با همین نقشه بسازید.

### فضای‌نام (Namespace) 🗂️
مثل یک «پوشه» برای کدها. جلوگیری می‌کند که دو کلاس هم‌نام با هم تداخل کنند.

```php
namespace Tavaan\Engine\Event;

class Dispatcher { /* ... */ }
```

> **تمثیل:** دو نفر به نام «علی» در کلاس. یکی «علی، کلاس الف» و دیگری «علی، کلاس ب». فضای‌نام همین کار را برای کلاس‌ها می‌کند.

## چطور با تَوان کار کنیم؟ 💻

### ساختار پروژهٔ تَوان

وقتی تَوان را نصب می‌کنید، این پوشه‌ها را می‌بینید:

```
tavaan-project/
├── bin/tvn              ← ابزار خط‌فرمان (CLI)
├── public/index.php     ← نقطهٔ ورود وب (HTTP)
├── core/                ← «هسته» — قلب تَوان
├── engines/             ← ۵۲ موتور — هر کدام یک ابزار
├── modules/             ← ماژول‌های HMVC (یعنی پروژهٔ شما)
├── config/              ← پیکربندی
├── routes/              ← مسیرها (URLها)
├── resources/           ← نماها، زبان‌ها
└── storage/             ← لاگ، کش
```

### دستورات پرکاربرد

| دستور | کار |
|---|---|
| `php bin/tvn serve` | اجرای سرور توسعه |
| `php bin/tvn info` | اطلاعات سیستم |
| `php bin/tvn engines` | لیست موتورهای نصب‌شده |
| `php bin/tvn version` | نسخهٔ تَوان |

> **تمثیل:** `bin/tvn` مثل یک «دستگیرهٔ همه‌کاره» است — با آن می‌توانید هر کاری در پروژه انجام دهید.

## ده قانون طلایی تَوان 📜

وقتی با تَوان کار می‌کنید، این ده قانون را در یاد داشته باشید (به آن‌ها «R1 تا R10» می‌گوییم):

| # | قانون | به زبان ساده |
|---|---|---|
| R1 | `declare(strict_types=1);` در هر فایل | تَوان سخت‌گیر است؛ نوع‌ها را جدی می‌گیرد. |
| R2 | فقط Autoloader هسته | نیازی به `require` دستی نیست. |
| R3 | هیچ پکیج خارجی | صفر‌وابستگی، قانون است. |
| R4 | بدون Property پویا | هر ویژگی کلاس باید از قبل تعریف شود. |
| R5 | هر خروجی عمومی = Interface | هر چیزی که بیرون می‌رود، یک «قرارداد» دارد. |
| R6 | هر موتور: Provider + Interface + Tests + Docs + Benchmark | موتور باید کامل باشد. |
| R7 | namespace از ریشهٔ ثبت‌شده | مثل `Tavaan\Engine\Event\`. |
| R8 | خطا = استثنا با کد و MessageId | خطاها شناسه دارند، نه فقط پیام. |
| R9 | Prepared Statement فقط | امنیت پایگاه‌داده جدی است. |
| R10 | قبل از Merge: تست + PHPStan + Benchmark | کد ناقص وارد پروژه نمی‌شود. |

> نگران نباشید اگر این‌ها الان برایتان ناآشناست. کم‌کم با آن‌ها آشنا می‌شوید. مهم این است که بدانید تَوان نظم را جدی می‌گیرد — و این نظم، به‌نفع شماست.

## سه گنج زبانی تَوان 🇮🇷

تَوان فارسی‌اول است. سه چیز در آن دیده می‌شود:

### ۱. تاریخ جلالی 📅
تَوان از موتور `jalali` برای تبدیل تاریخ میلادی به جلالی استفاده می‌کند. یعنی `1404/08/14` به‌جای `2025/11/04`.

تَوان به‌درستی با نیم‌فاصله رفتار می‌کند. «می‌رود» به‌جای «می رود».

## شما می‌توانید! 🌟

می‌دانم که شاید الان همه‌چیز روشن نباشد. فریمورک‌ها در نگاه اول ترسناک به‌نظر می‌رسند — پر از واژه‌های ناآشنا، فایل‌های زیاد، نمادهای عجیب (🔒، ⚠️، 🧪).

اما به من اعتماد کنید: هر برنامه‌نویس حرفه‌ای، روزی مبتدی بوده. هیچ‌کس با کدنویسی متولد نشده. تفاوت فقط در **پایداری** است — کمی هر روز، پیش می‌روید.

تَوان برای کمک به شما ساخته شده. مستنداتش ساده، فارسی، و پر از تمثیل است. اگر گیر کردید، به [`glossary-simple.md`](./glossary-simple.md) برگردید. اگر گیر کردید، به [`../examples/hello-world.md`](../examples/hello-world.md) بروید و یک پروژهٔ واقعی بسازید.

هر خط کدی که می‌نویسید، یک آجر است. هر آجر، خانه‌ای را کامل‌تر می‌کند.

شما می‌توانید. 🚀

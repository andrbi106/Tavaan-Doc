## چطور از این واژه‌نامه استفاده کنید؟ 🤔

برای هر واژه، چهار بخش داریم:

- **واژه:** نام فارسی + معادل لاتین.
- **تعریف:** یک جملهٔ ساده.
- **تمثیل:** یک مثال از دنیای واقعی.
- **نمونه:** قطعه کد یا مثال عملی (در صورت نیاز).

واژه‌ها از مفاهیم کلی به مفاهیم تَوانی پیش می‌روند. می‌توانید خط‌به‌خط بخوانید، یا فقط واژهٔ موردنظرتان را پیدا کنید.

## واژه‌ها

### ۱. فریمورک (Framework) 📚

**تعریف:** مجموعه‌ای از ابزارها و قواعد آماده که ساخت نرم‌افزار را ساده می‌کند.

**تمثیل:** مثل یک کتاب دستور پخت — به شما می‌گوید برای ساخت یک وب‌سایت، چه مراحلی را طی کنید.

**نمونه:**
```php
// تَوان یک فریمورک PHP است
$app = ApplicationBuilder::create()->boot();
```

---

### ۲. موتور (Engine) ⚙️

**تعریف:** یک واحد مستقل در تَوان که یک کار خاص انجام می‌دهد (مثل مسیریابی، رویداد، پایگاه‌داده).

**تمثیل:** مثل یک ابزار در جعبه‌ابزار — چکشی برای میخ، انبردست برای سیم. هر موتور یک ابزار است.

**نمونه:**
```
engines/event/        ← موتور رویداد
engines/router/       ← موتور مسیریاب
engines/database/     ← موتور پایگاه‌داده
```

---

### ۳. ماژول (Module) 📦

**تعریف:** یک واحد HMVC (سلسله‌مراتبی) که یک «دامنهٔ کاربردی» را پوشش می‌دهد — مثل نظرات، فروشگاه، انبار.

**تمثیل:** مثل یک اتاق در خانه — اتاق خواب، آشپزخانه، هال. هر اتاق یک کار خاص دارد.

**نمونه:**
```
modules/comment/      ← ماژول نظرات
modules/shop/         ← ماژول فروشگاه
modules/inventory/    ← ماژول انبار
```

---

### ۴. کیت (Kit) 🎯

**تعریف:** یک اپلیکیشن کامل ساخته‌شده از ماژول‌ها — مثل یک فروشگاه آماده، یک بلاگ آماده.

**تمثیل:** مثل یک «پکیج مبلمان» — شامل همهٔ اتاق‌ها است، آماده برای رفتن به خانه.

**نمونه:**
```
kits/blog/            ← کیت بلاگ
kits/shop/            ← کیت فروشگاه
kits/lms/             ← کیت مدیریت آموزش
```

---

### ۵. افزونه (Plugin) 🔌

**تعریف:** بسته‌ای از طرف ثالث که قابلیت جدیدی به تَوان اضافه می‌کند (و از قانون صفر‌وابستگی معاف است).

**تمثیل:** مثل اپلیکیشن‌هایی که روی گوشی نصب می‌کنید — خود گوشی از کارخانه آمده، اپ‌ها را بعد نصب می‌کنید.

**نمونه:**
```
plugins/example-seo/         ← افزونه سئو
plugins/example-analytics/   ← افزونه تحلیل
plugins/example-payment-gateway/ ← افزونه درگاه پرداخت
```

---

### ۶. وابستگی (Dependency) 🔗

**تعریف:** یک کد بیرونی که نرم‌افزار شما برای کار به آن نیاز دارد.

**تمثیل:** مثل این که برای روشن کردن چراغ، به شرکت برق وابسته باشید. اگر برق قطع شود، چراغ هم خاموش می‌شود.

**نمونه:**
```php
// در فریمورک‌های دیگر:
require 'vendor/autoload.php';  // این یک وابستگی است

// در تَوان: صفر وابستگی — خودنوشته!
```

> تَوان از قانون **ZeroDependency** (صفر‌وابستگی) پیروی می‌کند. هیچ کد بیرونی.

---

### ۷. کانتینر (Container) 🧰

**تعریف:** یک «انبار مرکزی» که اشیاء را می‌سازد، نگه می‌دارد، و در لحظهٔ نیاز تحویل می‌دهد.

**تمثیل:** مثل یک جعبه‌ابزار هوشمند — وقتی می‌گویید «چکش»، خودش چکش را به دستتان می‌گذارد.

**نمونه:**
```php
// گرفتن یک شیء از کانتینر
$cache = $this->make(CacheInterface::class);
```

---

### ۸. تزریق وابستگی (Dependency Injection / DI) 🤝

**تعریف:** روشی که در آن، اشیاء مورد نیاز یک کلاس از بیرون به آن داده می‌شود، نه این که خودش بسازد.

**تمثیل:** مثل این که یک کارگر، خودش به دنبال چکش نگردد، بلکه سرپرست چکش را به دستش بگذارد.

**نمونه:**
```php
// روش اشتباه (ساختن داخل کلاس):
class UserService {
    private $db;
    public function __construct() {
        $this->db = new Database();  // ❌ کلاس خودش می‌سازد
    }
}

// روش درست (تزریق):
class UserService {
    public function __construct(
        private DatabaseInterface $db  // ✅ از بیرون داده می‌شود
    ) {}
}
```

---

### ۹. رویداد (Event) 🔔

**تعریف:** پیامی که وقتی چیزی رخ می‌دهد، منتشر می‌شود و هر کس که علاقه‌مند باشد، آن را می‌شنود.

**تمثیل:** مثل زنگ خانه — وقتی کسی در می‌زند، زنگ به‌صدا درمی‌آید و همه در خانه می‌فهمند.

**نمونه:**
```php
// انتشار رویداد
Event::dispatch('user.registered', ['userId' => 42]);

// شنیدن رویداد
Event::listen('user.registered', function ($data) {
    // ارسال ایمیل خوش‌آمد
});
```

---

### ۱۰. میان‌افزار (Middleware) 🛡️

**تعریف:** لایه‌ای بین درخواست کاربر و کد اصلی، که می‌تواند درخواست را بررسی یا تغییر دهد.

**تمثیل:** مثل گارد امنیتی در ورود یک ساختمان — اول هویت شما را چک می‌کند، بعد اجازه می‌دهد وارد شوید.

**نمونه:**
```php
class AuthMiddleware {
    public function handle(Request $req, callable $next) {
        if (!$req->user()) {
            return redirect('/login');
        }
        return $next($req);
    }
}
```

---

### ۱۱. قرارداد (Contract / Interface) 📜

**تعریف:** یک «قول» در کد که می‌گوید یک کلاس چه متدهایی باید داشته باشد، بدون آنکه بگوید چطور.

**تمثیل:** مثل قرارداد کار — می‌گوید کارگر باید این کارها را انجام دهد، اما نمی‌گوید با چه ابزاری.

**نمونه:**
```php
interface CacheInterface {
    public function get(string $key): mixed;
    public function set(string $key, mixed $value, int $ttl): void;
}

// پیاده‌سازی قرارداد
class FileCache implements CacheInterface { /* ... */ }
class RedisCache implements CacheInterface { /* ... */ }
```

---

### ۱۲. فضای‌نام (Namespace) 🗂️

**تعریف:** روشی برای دسته‌بندی کدها و جلوگیری از تداخل نام‌ها.

**تمثیل:** مثل پوشه‌بندی در کامپیوتر — دو فایل به نام `report.pdf` می‌توانند در دو پوشهٔ متفاوت باشند بدون تداخل.

**نمونه:**
```php
namespace Tavaan\Engine\Event;

class Dispatcher { /* ... */ }

// کلاس کامل: Tavaan\Engine\Event\Dispatcher
```

> تَوان از ریشه‌های فضای‌نام ثبت‌شده استفاده می‌کند: `Tavaan\Core\`, `Tavaan\Engine\<Name>\`, `Modules\<Module>\`.

---

### ۱۳. خودبارگذار (Autoloader) 📚

**تعریف:** سیستمی که به‌طور خودکار فایل کلاس را پیدا و بارگذاری می‌کند وقتی از آن استفاده می‌کنید.

**تمثیل:** مثل یک کتاب‌دار هوشمند — هر وقت گفتید «کتاب فلان»، خودش می‌رود و از قفسه می‌آورد.

**نمونه:**
```php
// در فریمورک‌های دیگر:
require 'vendor/autoload.php';

// در تَوان: Autoloader خودنوشته
// (بدون نیاز به require دستی)
$dispatcher = new \Tavaan\Engine\Event\Dispatcher();
```

> تَوان از ADR-0005 برای نوشتن Autoloader خودنوشته استفاده می‌کند — صفر‌وابستگی حتی در بارگذاری کد.

---

### ۱۴. سرویس‌ارائه‌دهنده (ServiceProvider) 🏪

**تعریف:** کلاسی که یک «سرویس» را در کانتینر ثبت می‌کند — مثل افتتاح یک مغازه.

**تمثیل:** مثل افتتاح یک مغازه — صاحب مغازه می‌گوید «من این کالا را می‌فروشم»، و مشتریان می‌دانند کجا بروند.

**نمونه:**
```php
class EventServiceProvider extends ServiceProvider {
    public function register(): void {
        $this->app->singleton(
            DispatcherInterface::class,
            EventDispatcher::class
        );
    }

    public function boot(): void {
        // ثبت شنوندگان پیش‌فرض
    }
}
```

---

### ۱۵. فاساد (Facade) 🎮

**تعریف:** یک «رابط ساده» برای دسترسی به یک سرویس پیچیده در کانتینر، بدون نیاز به دانستن جزئیات.

**تمثیل:** مثل کنترل تلویزیون — با یک دکمه روشن می‌کنید، بدون آنکه بدانید داخل تلویزیون چه می‌گذرد.

**نمونه:**
```php
// بدون فاساد (روش طولانی):
$dispatcher = $container->make(DispatcherInterface::class);
$dispatcher->dispatch('user.registered', $data);

// با فاساد (روش ساده):
Event::dispatch('user.registered', $data);
```

---

### ۱۶. لایه (Layer) 🏢

**تعریف:** سطحی از معماری که مسئولیت خاصی دارد (مثل لایهٔ نمایش، لایهٔ کاربرد، لایهٔ داده).

**تمثیل:** مثل طبقات یک ساختمان — طبقهٔ همکف پذیرش، طبقهٔ اول کار، طبقهٔ دوم استراحت.

**نمونه:**
```
┌──────────────┐
│   نمایش      │  ← View (HTML)
├──────────────┤
│   کاربرد     │  ← Controller (منطق)
├──────────────┤
│   دامنه      │  ← Model (قوانین کسب‌وکار)
├──────────────┤
│   داده       │  ← Database
└──────────────┘
```

---

### ۱۷. HMVC — کنترلر سلسله‌مراتبی 📦

**تعریف:** الگویی که در آن، ماژول‌ها می‌توانند داخل هم قرار بگیرند و هر کدام کنترلر/مدل/نمای خود را داشته باشند.

**تمثیل:** مثل جعبه‌های روسی (matryoshka) — هر جعبه داخل جعبهٔ بزرگ‌تر است، اما خودش کامل است.

**نمونه:**
```
shop/                 ← ماژول فروشگاه (پدر)
├── catalog/         ← زیرماژول کاتالوگ
├── cart/            ← زیرماژول سبد خرید
└── checkout/        ← زیرماژول تسویه
```

---

### ۱۸. مونولیت ماژولار (Modular Monolith) 🏠

**تعریف:** نوعی معماری که کل سیستم یک پروسه است، اما داخلش به ماژول‌های مستقل تقسیم شده.

**تمثیل:** مثل یک خانه با اتاق‌های جدا — یک ساختمان است، اما هر اتاق جدا است و کار خاصی دارد.

**نمونه:**
```
tavaan-app/        ← یک پروسه (مونولیت)
├── modules/shop/  ← ماژول فروشگاه (مستقل)
├── modules/hr/    ← ماژول منابع انسانی (مستقل)
└── modules/blog/  ← ماژول بلاگ (مستقل)
```

> در تَوان، مونولیت ماژولار پیش‌فرض است. اگر روزی خواستید مایکروسرویس شوید، هر ماژول می‌تواند جدا شود.

---

### ۱۹. رویداد‌محور (Event-Driven) 📡

**تعریف:** الگویی که در آن، بخش‌های سیستم با انتشار و شنود رویداد با هم صحبت می‌کنند، نه با فراخوانی مستقیم.

**تمثیل:** مثل سیستم اطلاع‌رسانی فرودگاه — وقتی پرواز عقب می‌افتد، اعلان می‌شود و همه می‌فهمند، بدون آنکه یکی‌یکی به مسافران زنگ بزنند.

**نمونه:**
```php
// ماژول فروش، رویداد انتشار می‌دهد
Event::dispatch('order.placed', ['orderId' => 100]);

// ماژول انبار، رویداد را می‌شنود
Event::listen('order.placed', function ($data) {
    Inventory::reduce($data['orderId']);
});
```

---

### ۲۰. شش‌ضلعی (Hexagonal) 🐝

**تعریف:** الگویی که در آن، منطق اصلی در «مرکز» است و درگاه‌ها (ports) در اطراف — هر درگاه می‌تواند به یک بیرون (adapter) متصل شود.

**تمثیل:** مثل یک کندوی عسل — مرکز (منطق) ثابت است، اما هر خانهٔ شش‌ضلعی یک ورودی به بیرون دارد.

**نمونه:**
```
            ┌─────────────┐
   HTTP →   │             │   ← MySQL
            │   Domain    │
   CLI →    │   Logic     │   ← PostgreSQL
            │             │   ← SQLite
   API →    │             │
            └─────────────┘
```

> تَوان از این الگو برای «آمادگی مایکروسرویس» استفاده می‌کند — هر درگاه قابل تعویض است.

---

### ۲۱. SQL / پایگاه داده (Database) 🗄️

**تعریف:** سیستمی که داده‌ها را به‌صورت جدول ذخیره می‌کند. SQL زبان صحبت با آن است.

**تمثیل:** مثل یک کابینت بایگانی — هر کشو یک جدول، هر پرونده یک ردیف.

**نمونه:**
```sql
CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(200)
);

INSERT INTO users (id, name, email) VALUES (1, 'Ali', 'ali@example.com');
SELECT * FROM users WHERE name = 'Ali';
```

---

### ۲۲. ORM — نگاشت شیء-رابطه‌ای 🌉

**تعریف:** ابزاری که داده‌های جدول پایگاه‌داده را به «شیء» در کد تبدیل می‌کند، برعکس.

**تمثیل:** مثل یک مترجم — شما به فارسی می‌گویید «کاربری به نام علی»، ORM آن را به SQL ترجمه می‌کند.

**نمونه:**
```php
// بدون ORM (SQL دستی):
$pdo->query("SELECT * FROM users WHERE name = 'Ali'");

// با ORM تَوان:
$ali = User::where('name', 'Ali')->first();
$ali->email = 'new@example.com';
$ali->save();
```

---

### ۲۳. API — رابط برنامه‌نویسی 🍽️

**تعریف:** مجموعه‌ای از «نقاط دسترسی» که نرم‌افزارهای دیگر می‌توانند از طریق آن با سیستم شما صحبت کنند.

**تمثیل:** مثل منوی رستوران — مشتری از منو انتخاب می‌کند، آشپز غذا را می‌سازد، گارسون می‌آورد. مشتری با آشپز صحبت نمی‌کند.

**نمونه:**
```
GET    /api/users         ← لیست همه کاربران
GET    /api/users/42      ← کاربر شماره ۴۲
POST   /api/users         ← ساخت کاربر جدید
PUT    /api/users/42      ← ویرایش کاربر ۴۲
DELETE /api/users/42      ← حذف کاربر ۴۲
```

---

### ۲۴. CLI — رابط خط‌فرمان ⌨️

**تعریف:** روشی برای صحبت با کامپیوتر از طریق تایپ دستور در ترمینال.

**تمثیل:** مثل چت کردن با کامپیوتر — شما یک خط تایپ می‌کنید، او جواب می‌دهد.

**نمونه:**
```bash
$ php bin/tvn serve
Tavaan development server started on http://127.0.0.1:8000

$ php bin/tvn info
PHP version:    8.3.32
Tavaan version: 0.4.0
Engines loaded: 52

$ php bin/tvn engines
container    ✅ loaded
config       ✅ loaded
event        ✅ loaded
...
```

---

### ۲۵. ZeroDependency — صفر‌وابستگی 🧱

**تعریف:** قانون تَوان که می‌گوید هیچ پکیج بیرونی نباید در `core/` و `engines/` باشد.

**تمثیل:** مثل ساختن خانه با مواد خام (خشت، آجر، چوب) — نه با پنل‌های پیش‌ساخته از کارخانه.

**نمونه:**
```php
// ❌ در تَوان ممنوع:
use Psr\Container\ContainerInterface;
use Symfony\Component\HttpFoundation\Request;

// ✅ در تَوان:
use Tavaan\Core\Container\ContainerInterface;
use Tavaan\Engine\Http\Request;
```

> این قانون در ADR-0004 ثبت شده و توسط ابزار `audit_tavaan.py` به‌صورت خودکار بررسی می‌شود.

## واژه‌های پاداشی 🎁

این چند واژه هم بد نیست بدانید:

### خودکار (Autoloader)
همان «خودبارگذار» (شماره ۱۳) — با نام کوتاه.

### کنترلر (Controller)
کلاسی که درخواست کاربر را می‌گیرد و جواب می‌دهد.

> **تمثیل:** مثل گارسون رستوران — سفارش می‌گیرد، به آشپزخانه می‌برد، غذا را می‌آورد.

### مدل (Model)
نمایش داده‌ها و قوانین کسب‌وکار.

> **تمثیل:** مثل دستور پخت و مواد اولیه در آشپزخانه.

### نما (View)
آنچه کاربر می‌بیند (HTML).

> **تمثیل:** مثل بشقاب و چیدمان میز — غذا همان است، اما نحوهٔ ارائه مهم.

چند واژهٔ لاتین که شاید تلفظشان برایتان سخت باشد:

| واژه | تلفظ فارسی |

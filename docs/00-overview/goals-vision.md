## چرا تَوان؟

تَوان (به‌معنای «قدرت، توانایی، توانمندسازی») فریمورک PHP 8.2+ فارسی‌اول است که بر پایهٔ قانون **ZeroDependency** بنا شده است.

| مشکل رایج | پاسخ تَوان |
|---|---|
| وابستگی سنگین به پکیج‌های بیرونی | صفر‌وابستگی — همه‌چیز خودنوشته |
| کدهای Deprecated | سند الزامات PHP 8.2+ + چک‌لیست ممنوعه‌ها |
| امنیت پس‌رو | لایهٔ امنیتی درون‌ذاتی در هر موتور |
| عدم کنترل زنجیرهٔ تأمین | ۰ آسیب‌پذیری خارجی |

## اهداف کلان (G1-G5)

| ID | هدف | شاخص |
|---|---|---|
| G1 | ZeroDependency کامل | ۰ پکیج بیرونی در core/ و engines/ |
| G2 | نصب آفلاین | اجرای `php bin/tvn serve` بدون اینترنت |
| G3 | فارسی‌اول | RTL، جلالی، واژه‌نامه دوزبانه |
| G4 | خودکفایی | همهٔ قابلیت‌ها خودنوشته |
| G5 | آمادگی مایکروسرویس | معماری Hexagonal + Event-Driven |

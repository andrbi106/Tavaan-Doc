## توصیه‌های اولویت‌دار

### ۱) تکمیل فازهای بنیاد ✅
فازهای M0-M5 کامل هستند. هیچ اقدامی لازم نیست.

### ۲) تکمیل فاز وب (M6-M9)
این فازها **پیش‌نیاز همهٔ فازهای بعدی** هستند. توصیه:
- M6 (http): پیاده‌سازی کامل HTTP Kernel
- M7 (router): Compiled Trie با ≤۵µs match
- M8 (session/cookie/cors): تکمیل
- M9 (view/jalali): View Engine با `.tv.php`

### ۳) تکمیل فاز داده (M10-M13)
پس از وب، داده حیاتی است:
- M10 (database): بزرگ‌ترین موتور (۱۱K LOC) — نیاز به پیاده‌سازی واقعی
- M11 (schema/migration): ابزار توسعه
- M12 (orm): Active Record + Repository

### ۴) تکمیل فاز امنیت (M14-M16)
پس از داده:
- M14 (cache/queue/schedule): زیرساخت
- M15 (auth): احراز هویت
- M16 (rbac/security/audit): کنترل دسترسی

### ۵) رفع نقض قوانین 🔒
از گزارش ممیزی (DOC-AUDIT):
- ❌ ۸۳ فایل بدون `declare(strict_types=1)` (R1)
- ❌ ۱۲۳ استثنای خام (R8)

### ۶) افزودن آزمون 🔒
هر موتور نیاز به:
- Unit Tests (≥۹۰٪ پوشش)
- Feature Tests (جریان اصلی)
- Benchmark (اهداف عملکرد)

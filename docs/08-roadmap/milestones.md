## قواعد هماهنگی فازها 🔒

### ۱) وابستگی فقط به لایه‌های قبلی
🔒 هر لایه فقط به لایه‌های **قبلی** وابسته است (طبق DEPENDENCIES.md).

### ۲) ترتیب اجباری
🔒 فاز N فقط پس از تکمیل فاز N-1 شروع می‌شود.

### ۳) مرز ماژول
🔒 موتورها فقط از طریق سه درگاه (Container, Events, EngineBus) ارتباط می‌گیرند.

### ۴) هر فاز = +1 نسخه
🔒 با تکمیل هر فاز، نسخه یک واحد افزایش می‌یابد (طبق DOC-126).

### ۵) انتقال لایه = carry
🔒 انتقال بین لایه‌ها = carry به MINOR (PATCH به 0 بازمی‌گردد).

### ۶) بدون پرش
🔒 هیچ پرش نسخه وجود ندارد — از 0.0.0 تا 1.0.0 گام‌به‌گام.
